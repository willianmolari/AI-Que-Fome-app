Política de Privacidade — Ai que fome

Vigência: 21 de novembro de 2026.

O aplicativo Ai que fome respeita sua privacidade. Esta política explica quais dados são usados e como são tratados.

1. Dados armazenados no dispositivo

Os registros do diário alimentar, metas, perfil (nome, idade, sexo, altura, peso atual, peso alvo, percentual de gordura), histórico de dobras cutâneas, histórico de pesagens, preferência de tema e chave opcional da API do USDA são salvos apenas no seu dispositivo, por meio do armazenamento local do Android (SharedPreferences). Eles não são enviados a servidores próprios.

2. Login com Google

O login é opcional e usa o Firebase Authentication. Quando você entra, recebemos do Google apenas seu nome e endereço de e-mail para identificar a conta. Essas informações são usadas exclusivamente para autenticação e não são compartilhadas com terceiros para fins de publicidade.

3. Serviços de terceiros

  • Firebase Authentication (Google) — autenticação.
  • Open Food Facts — quando você faz uma busca, consultas são enviadas à API pública para localizar produtos do Brasil.
  • USDA FoodData Central — consulta opcional de alimentos, feita somente quando você utiliza essa fonte.

O aplicativo não usa anúncios, não possui telemetria própria e não compartilha os dados do seu diário com esses serviços.

4. Permissões

É solicitado acesso à internet para as consultas descritas acima. Não são solicitados acesso a câmera, contatos, localização nem arquivos.

5. Exclusão de dados

Você pode excluir registros do diário, dobras e pesagens diretamente no aplicativo. A preferência de conta pode ser removida ao sair da conta. Para solicitar a exclusão dos dados de autenticação mantidos pelo Firebase, entre em contato pelo e-mail abaixo.

6. Segurança

As comunicações com o Firebase e com as APIs de alimentos utilizam HTTPS. Os dados locais permanecem no armazenamento privado do aplicativo no dispositivo.
